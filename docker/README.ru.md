# TS3 Sound Bot - установщик с Docker

Готовый к установке музыкальный бот для TeamSpeak 3 на базе поддерживаемого форка [TS3AudioBot](https://github.com/goD0S/TS3AudioBot).
Играет YouTube и прямые ссылки, есть плейлисты, очередь и веб-панель (русский / английский, темы тёмная / светлая / хакерская,
удобно с телефона). Всё работает в Docker, кроме самого Docker ничего в систему не ставится.

[English version](README.md)

## Установка

Нужны **Docker** (Docker Desktop на Windows / macOS, Docker Engine с плагином compose на Linux) и интернет
(первая сборка скачивает исходники бота и занимает несколько минут).

- **Windows:** дважды щёлкните `install.cmd` (или `powershell -ExecutionPolicy Bypass -File install.ps1`).
- **Linux / macOS:** `bash install.sh`

Установщик задаёт вопросы (на русском или английском):

| Вопрос | Примечание |
|---|---|
| Адрес сервера TeamSpeak | IP или имя, можно с `:портом`. `localhost` заменится на `host.docker.internal` (бот живёт в контейнере). |
| Пароль сервера | Необязательно. |
| Ник бота, канал | Канал необязателен (`Лобби/Музыка` или `/12`). |
| Кто открывает веб-панель | Только этот компьютер или локальная сеть. |
| Порт панели и ключ доступа | Если нажать Enter, ключ создаётся случайно. Это единственный пароль панели. |
| Дополнительные настройки | По желанию: прокси для YouTube, спрашивается, только если ответить «да». |

Потом он собирает образ, запускает бота и выводит адрес панели и ключ.
Панель работает по HTTPS с самоподписанным сертификатом: браузер один раз предупредит, так и должно быть.

Без вопросов: `install.ps1 -NonInteractive -Server 192.168.1.10:9987 -Nickname MusicBot -Access lan -Port 58913`
или `bash install.sh --non-interactive --server 192.168.1.10:9987 --nickname MusicBot --access lan --port 58913`
(ещё параметры: `-Language`, `-ServerPassword`, `-Channel`, `-Key`, `-Proxy`, `-ContainerName`, `-NoStart`).

## Использование

- Откройте панель, войдите по ключу. На вкладке «Главная» введите название или вставьте ссылку.
- В чате TeamSpeak пишите боту команды с `/`, например `/play <ссылка>`, `/help`.
  Все команды с описаниями и консоль есть в панели: Настройки > Команды.
- По желанию положите в `data/` файл `cookies.txt` с cookies YouTube (формат Netscape), если YouTube просит подтвердить, что вы не бот.

## Управление

В этой папке: `docker compose logs -f`, `docker compose stop`, `docker compose start`.
Обновить бота (свежий yt-dlp, пересборка): снова запустите установщик и выберите «Обновить». «Перенастроить» задаст вопросы заново,
плейлисты и личность бота сохранятся. Удалить всё: `docker compose down -v`, затем удалите папку.

## Файлы

В `data/` лежат ваши настройки, плейлисты и логи (создаются установщиком, в пакет не входят). В `.env` - порты и имена.
`bot/` - наши патчи для бота, `webui/` - веб-панель (Vue 3 + Vite; переводы в `webui/src/locales`).
